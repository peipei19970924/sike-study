# 塑形魔方健身 · 五课学习中心

一个文件、不联网、能天天用的学习器：**健身 · 拳击 · 膳食营养 · 解剖 · 儿童青少年训练**，另带一个能算 BMI／热量／配比的**工具页**。

现在共 **212 张卡**（健身 40 · 拳击 40 · 营养 56 · 解剖 40 · 儿童 36），每科按 **L1 入门 → L2 结构 → L3 应用 → L4 进阶** 四级排列；另有 30 张必会卡、12 条前沿速递、7 大营养素速查、膳食宝塔图与「热量四步走」引导。内容**每月更新一次**，版本号见数据页。

双击 `index.html` 就能学，进度存在你自己的浏览器里。

## 1. 五分钟上手

1. 双击 `index.html`（推荐 Chrome / Edge / 手机浏览器）。

## 3. 学习规定（每天怎么学最省时间）

- **一次 10 分钟，一天一次。** 打开就是「今日任务」，做完就关，别刷。
- **顺序是先读再做。** 阅读态读完原文再点自测；直接猜答案等于没学。
- **答错不要紧，但要看反馈。** 答错后弹「依据」一行，把那条依据读一遍再进下一张。
- **每天 3 张新卡 + 全部到期复习**（可在数据页改新卡数）。新卡是「往前推」，复习是「不忘记」，两头都要。
- **先看「学习路径」（速览页顶部）**：它按 L1→L4 显示每科进度条，告诉你现在在哪儿、下一步学哪一级。由浅入深比乱学快得多。
- **节奏**：先刷完 30 张必会卡（速览页），再按 12 周主线推进。五科交错着学，比一口气啃完一科记得牢。
- **每月更新一次**：每月会补新卡、修订过期内容（比如指南改版、新共识），版本号会从 2027.01 往上走。看到版本号变了，说明有值得重看的内容。
- **别追求一次学完。** 212 张按每天 5 张新卡算约 43 天过一遍，之后靠复习维持；真正记住靠的是重复出现的时机，不是当天记多少。额度也随时能「继续学」，不用被每日配额卡住。
- **疼痛、头晕、关节异响就停。** 这套卡片是学习材料，不是医疗建议；身体信号优先于任何「应该」。

## 4. 工具页（算一算）

顶部第 4 个标签 **工具**，填四五个数就能算出你自己的一天：

- **输入**：性别（男/女）、年龄、身高、体重、活动档（七档，把「运动量」和「劳动强度」都算进去：久坐 1.2 / 轻活动 1.375 / 轻体力劳动 1.5 / 中活动 1.55 / 中体力劳动 1.75 / 重活动 1.725 / 重体力 1.9）。
- **输出四个数**：BMI 与分级（中国标准：<18.5 偏轻、18.5–23.9 正常、24–27.9 超重、≥28 肥胖）、正常体重区间、基础代谢（Mifflin-St Jeor 公式）、维持热量。
- **三档目标**：减脂 −20%、维持、增肌 +10%，每档都直接给出碳水／蛋白／脂肪的克数（蛋白减脂 1.8 g/kg、维持 1.6、增肌 1.8；脂肪占 25%；碳水补足余量）。
- **劳动强度对照**：轻体力 PAL 1.5（办公室、程序员、教师、医生、会计、司机、客服、店员、保安）、中体力 PAL 1.75（护士、销售外勤、餐厅服务员、幼师、护理员、巡检、快递分拣、保洁）、重体力 PAL 2.0（建筑、搬运、农民、矿工、伐木、渔业、竞技运动员训练日）。
- **热量怎么算：四步走（引导通路）**：① 基础代谢（列出算式和结果）→ ② 乘你的活动／劳动系数（写清「轻体力劳动 ×1.5、中体力 ×1.75、重体力 ×2.0」）→ ③ 得到维持热量（TDEE，你的基准线）→ ④ 选目标得出你的数（减脂 ×0.8 / 维持 ×1 / 增肌 ×1.1）。看完这四步，你就知道自己的目标热量是怎么来的，而不是抄一个数字。
- **膳食宝塔**：按《中国居民膳食指南（2022）》画的五层图（谷薯 → 蔬果 → 鱼禽肉蛋 → 奶豆坚果 → 油盐），每层写推荐量和一句「坑」。下面直接说明：**宝塔本身就是一种饮食模式**，不是营养素清单——照结构搭一餐，营养素自然齐。
- **七大营养素速查**：碳水／蛋白／脂肪／维生素／矿物质／水／膳食纤维，各写清「主要作用 · 每天多少 · 最常见的坑」，每条带证据等级 A/B/C。

几条用法：

1. **先选劳动档，再用体重变化校正**。公式算的是人群估算，误差约 ±10%（证据 B）。连着两周看体重：没动就减 300 千卡，掉太猛就加 300。
2. **别把估算当处方**。有慢性病、怀孕、进食障碍倾向，找注册营养师或医生，别照着计算器硬吃。
3. 结果只存在你自己这台设备（跟学习进度一样），别人扫码打开看到的是他自己的空白计算。

## 5. 内容规定（每张卡怎么写的）

每张卡都是同一张骨架，所以学起来不用适应不同风格：

| 字段 | 规定 |
| --- | --- |
| 标题 `t` | 一句话说清这张卡解决什么问题，不用感叹号堆情绪 |
| 讲解 `b` | 80–140 字，先给结论再给原因；不写「众所周知」这类废话 |
| 要点 `p` | 3 条，每条一个可执行动作或一个判断标准 |
| 误区 `m` | 1 条最常见的错误做法，说明为什么错 |
| 自测 `q` | 三选一，只有一个正确；干扰项要「像对但错」，不能是明显废项 |
| 证据 `ev` | A / B / C，见第 5 节 |
| 年龄 `age` | 仅儿童科：适用年龄段，如 `0-3`、`6-18` |
| 更新 `upd` | 近期有更新结论的卡标年份，如 `2024` |
| 例子 `e` | 每张卡必有一段生活化例子：带具体数字或场景，让零基础的人「一想就明白」 |
| 新手 `n` | 每个例子后面跟一句可立即执行的做法（做什么、做多少），不写「要重视」这类空话 |

另外：

- **不写剂量以外没有依据的数字。** 出现的数字（如蛋白质 1.6 g/kg、睡眠 9–12 小时）都在依据一栏能追到出处或共识。
- **不制造恐惧，也不承诺奇迹。** 不用「必须」「绝对不能」这类绝对词，除非确实有硬性安全线（如儿童不做最大重量测试）。
- **儿童科单独成立**，不和成人卡混写：同一个动作在 6 岁和 16 岁的做法、负荷、风险都不同。
- **每张卡都必须有例子和新手做法**：讲解负责「说清」，例子负责「看懂」，新手做法负责「明天就能做」。缺任何一项 `build.py` 会报错。
- **例子要带数字或具体场景**（「60 公斤蹲 8 次」「一碗饭约 200 千卡」），不要停在「要适量」「因人而异」。

## 6. 证据等级怎么读

每张卡都有徽章，点开详情能看到一行「依据」。

| 等级 | 含义 | 见到时怎么用 |
| --- | --- | --- |
| **A 强** | 多个高质量研究一致，或权威机构立场声明/指南明确（ACSM、NSCA、AAP、WHO、ISSN 等） | 可以直接照做 |
| **B 中** | 有中等证据或普遍专业共识，但结论有边界条件、个体差异大 | 照做，同时留意自己的反应 |
| **C 有限** | 只有机制推断、小样本、或领域内仍有争议 | 知道有这回事就行，别当铁律 |

自测页脚的那行依据，写的是这张卡的结论来自哪一类材料（如「训练学教科书共识 + ACSM 抗阻训练立场」「儿童力量训练国际共识」），方便你自己复核。

**速览页**把 30 张必会卡按科列出来，带证据等级；下面是**前沿速递**，10 条近年更新的结论（标了年份），每条指向对应卡片——想知道「最近变了什么」，看这一块。

## 7. 间隔重复是怎么排的

答对一次，这张卡下次出现的间隔按 1 → 2 → 4 → 7 → 15 → 30 天往后推；答错就退回 1 天并记一次错。box ≥ 3 记为「已掌握」。

所以：

- 首页的「今天还有 N 张」= 到期复习 + 今天还没学的新卡。
- 短期内天天见到同一张是正常的（刚学的卡间隔短），学稳之后几个月才见一次。
- 数据页的「最该重看的卡」按答错次数排序，考试前扫这里最划算。

## 8. 加卡、扩科、改内容

所有内容都是纯文本，改起来不需要编程。

1. 在 `src/` 里找到对应科目：`data-fit.js` 健身、`data-box.js` 拳击、`data-nut.js` + `data-nut2.js` 营养、`data-ana.js` 解剖、`data-kid.js` 儿童。
2. 照现有格式加一张（注意是数组，逗号别漏）：

```js
{id:"fit-25",s:"健身",lv:2,t:"标题写这里",b:"讲解 80-140 字。",
 p:["要点一","要点二","要点三"],m:"常见误区：……",ev:"B",
 q:{a:"下面哪种做法最符合？",o:["干扰项一","正确答案","干扰项二"],i:1,w:"为什么这么选。"}},
```

再在 `src/ex-fit.js`（举例子表）里给同一张卡补一条，字段名要和 id 对上：

```js
window.EX["fit-25"] = { e: "带数字或场景的例子，两三句讲透。", n: "新手明天就能做的一步，说清做多少。" };
```

3. 重新生成并自检（在本文件夹）：

```
python src/build.py        # 合成 index.html + 结构校验
node src/test-engine.js    # 引擎行为测试（改逻辑时才必要）
```

`build.py` 会检查：id 不重复、字段齐全、答案索引在 0–2、每题三选项互不相同、每张卡都有证据等级、每张卡都有例子和新手做法（缺哪张直接列出 id）。任何一项不过就会报出来。

- **新增科目**：在 `src/` 加 `data-xxx.js`，在 `build.py` 的拼接列表里加进去，再在 `app.js` 顶部的 `SUBS` 里加一行 `{s:"科目名", c:"#颜色"}`。
- **改证据/必会/前沿**：`src/meta.js`，一个文件管三张表（`EVID` 证据、`KEY` 必会、`UPD` 更新年份、`FRESH` 前沿速递）。
